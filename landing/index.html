Two axes

One to make it. One to keep it.

The suite splits along the grain of real work: getting from an idea to a shipped thing, and keeping that thing good, durable, and self-improving.

The MAKE axis

Idea → shipped thing

From a spark to a deliverable. These skills shape how a thing gets thought about, planned, designed, and assembled.

The KEEP axis

Good, durable, self-improving

How it fits together

The two axes close a loop.

build → review → compound → context → sharper next think ↺

Make produces the thing. Keep makes it better and remembers why. The lesson from review feeds the compounding map; the map feeds the context scaffold; the next prompt starts from everything the last one learned. The loop tightens with every turn.

Design promises

Four things every skill keeps.

Standalone

No plugin deps. Every skill runs on its own — nothing else to install.

Never asks you questions

It infers what it needs and produces. No interrogation loop.

Clear over clever

Legible scaffolds beat impressive ones. You can read what it made.

It compounds

Each pass leaves something reusable behind for the next one.

Why meta-prompting

Write one prompt that teaches a model how to think.

Instead of writing a fresh prompt per task, write one reusable prompt that teaches a model how to think about a whole category of problems. Give it a scaffold — roles, steps, slots — not examples to imitate.

Because the scaffold is example-agnostic, a model can apply it to itself: refine the prompt, run it, fold the result back in. That recursion is the whole engine behind Meta-Suite — and the reason the loop gets sharper instead of merely repeating.
