# _archive — internal working documents (PRUNABLE)

This folder holds the internal reasoning behind meta-suite: the meta-plan, the skill specs, and the
synthesized research. **None of it is required for the plugin to function.** It is kept for
provenance and future maintenance, and is safe to delete before publishing if you want the repo
leaner.

To prune for a clean public release:

```bash
rm -rf _archive
```

Nothing in `skills/`, `.claude-plugin/`, `README.md`, `landing/`, or `docs/` references this folder.
