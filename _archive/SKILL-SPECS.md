# Skill specs for the 5 new skills
*(Worked with the /meta-mvp intake+spec discipline — used to finalize the published skills, not to
build a throwaway MVP. Internal.)*

Shared contract (all 5): silent intake (auto-classify, never ask) → run typed/categorical reasoning
internally → emit plain-language deliverable → offer (one line) to reveal internal work only if
asked → pipeline-mode friendly (emit just the structured artifact when invoked by another skill).

### meta-compound
- **Lineage (abstracted, not referenced in-skill):** the "compounding" loop — each unit of work
  makes the next easier; Frame→Do→Review→Capture→Repeat; invest in the system; capture/retrieval/
  discoverability/refresh.
- **Output:** compounding map · top-3 leverage investments · capture/retrieval/refresh policy · first move.

### meta-craft
- **Lineage (abstracted):** the craft constitution — ETC (Easier To Change), "clear beats clever,"
  smallest change, no premature abstraction, validate at boundaries, prove it works, definition of done.
- **Output:** tailored craft constitution (5–8 rules) · slop-vs-craft contrast · evidence-based Definition of Done.

### meta-review
- **Lineage (abstracted):** parallel persona/lens review; P1/P2/P3; blind-spot probes (hardest
  decision / rejected alternatives / least confident); precedence-ordered fixes; lesson capture.
- **Output:** prioritized findings · blind-spot probes · ordered fix list · reusable lesson atom.

### meta-research
- **Lineage (abstracted):** decompose→fan-out→triage→cross-verify(adversarial)→synthesize→capture;
  search-before-generate; confidence levels; knowledge atoms; honesty about uncertainty.
- **Output:** sourced brief · per-conclusion confidence + open questions · sources · 1–3 knowledge atoms.

### meta-context
- **Lineage (abstracted):** durable plain-markdown substrate; progressive-disclosure load policy;
  compression to atoms; persistence/handoff write-back; discoverability index; anti-rot.
- **Output:** 4-policy context plan · discoverability index · droppable-in starter scaffold · first move.
