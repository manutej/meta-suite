# 10 · Vision ledger

**What this file is.** The owner's stated requirements, paraphrased faithfully from the design
conversation of 2026-10-29, numbered so the spec can be audited against them. This is the source of
truth for fidelity reviews.

**The rules.**
- Spec changes never edit this file.
- Only the owner adds or amends entries, and each change gets a decision entry.
- At every milestone exit, a **cross-tier fidelity review** checks the spec and build against this
  ledger (D-055).
